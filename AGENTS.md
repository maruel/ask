# ask

Install Go and uv. Run Python commands with `uv run --locked`.
Use `make help` to discover targets and `make git-hooks` to install hooks.
Run `make fix`, `make verify`, and `make test` before committing.
`make test` runs coverage and benchmark smoke checks.
